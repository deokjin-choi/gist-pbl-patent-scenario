## 3. 저장소 폴더 구조 (Directory Structure)

본 저장소는 초보자도 쉽게 자료를 찾고 관리할 수 있도록 다음과 같이 5개의 핵심 폴더로 구성되어 있습니다.

```text
gist-pbl-patent-scenario/
├── README.md               # 저장소 개요 및 사용 가이드 (본 파일)
├── meetings/               # [1. 회의록] 정기/비정기 회의록 및 아이디어 기록
├── docs/                   # [2. 자료 공유] 참고 논문, 특허 분석 자료 등
│   └── references/         # 선행 연구 논문, 특허 PDF, 기술 문헌
├── paper/                  # [3. 논문 작성] 학술지 투고용 논문 관련 자료
│   ├── draft/              # 논문 초안 (Word, HWP, LaTeX 등)
│   ├── figures/            # 논문에 들어갈 주요 시각화 차트 및 이미지
│   └── final/              # 최종 제출/투고용 논문 완생본
├── results/                # [4. 연구 산출물] PBL 진행 실적 및 발표 자료
│   ├── weekly_reports/     # 주차별/단계별 중간 보고서
│   └── presentations/      # 중간/최종 발표 PPT 및 PDF 자료
└── src/                    # [5. 분석 코드] 데이터 분석 및 시나리오 생성 스크립트
    └── scenario_pipeline/  # 전처리, GMM 분석, 시나리오 생성 코드 (Python 등)
```

## 4. 초보자를 위한 GitHub 사용 가이드 (웹 이용 권장)

터미널(명령어) 사용이 익숙하지 않은 팀원들은 **GitHub 웹사이트에서 직접 파일을 올려 공유**하는 방식을 권장합니다.

### 4.1. 웹에서 파일 업로드하는 방법
1. 올리고 싶은 대상 폴더(예: `meetings/`, `docs/references/`, `results/weekly_reports/` 등)로 이동합니다.
2. 우측 상단의 **[Add file]** 버튼 클릭 후 **[Upload files]**를 선택합니다.
3. 올릴 파일을 드래그 앤 드롭(Drag & Drop)하여 업로드 영역에 넣습니다.
4. 화면 하단의 **[Commit changes]** 버튼을 누르면 업로드가 완료됩니다.

### 4.2. 파일명 및 커밋 작성 규칙 (권장)
여러 명이 함께 작업하므로 아래의 규칙을 지켜주시기 바랍니다.

* **파일명에 날짜나 버전 포함하기:**
  * 예: `20261001_회의록.docx`
  * 예: `20261015_주차별보고서.pdf`
  * 예: `paper_draft_v1.0.docx`
  * 예: `scenario_matrix_fig1.png`
* **파일 업로드 시 커밋 메시지(Commit message) 남기기:**
  * `[회의록] 2주차 정기 회의록 업로드`
  * `[자료] Edge AI 관련 핵심 특허 논문 추가`
  * `[보고서] 4주차 진행 상황 보고서 공유`
  * `[코드] 특허 텍스트 전처리 파이썬 스크립트 업로드`

## 5. 폴더별 세부 역할 및 활용 규칙

* **meetings/ (정기 회의록)**
  * 격주 단위 정기 회의 및 팀 미팅의 안건, 결정 사항, 팀원별 Action Item을 기록하여 업로드합니다.
* **docs/ (참고 자료 공유)**
  * 프로젝트 진행 과정에서 참조해야 할 선행연구 논문, 특허 명세서, 분석 보고서 등을 공유합니다.
* **paper/ (논문 작성 전용)**
  * 작성 중인 논문 파일(`draft/`)과 논문에 들어가는 시각화 자료 및 이미지(`figures/`)를 구분하여 관리합니다.
* **results/ (PBL 실적 및 발표)**
  * 수업 제출용 주차별 보고서와 발표용 PPT 파일이 들어갑니다. 과제 평가 시 핵심 증빙 자료로 활용됩니다.
* **src/ (소스 코드)**
  * 데이터 수집, 전처리, 분석 알고리즘, 시나리오 생성 시 사용된 Python 파일이나 주피터 노트북(`.ipynb`)을 정리하여 올립니다.
